# Kaplan Business Atlas

An interactive map of businesses documented in the Kaplan collection. The default view covers commercial items dated 1801–1900. Counts represent collection items, so multiple items can document one business.

Open `index.html` in a browser or serve the repository locally:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Visit <http://127.0.0.1:8000/>. The map loads its libraries and basemap over the internet.

Use **Marker colors** for the map key and **Verified addresses** for entries checked against images. Address candidates from OCR remain provisional. A verified transcription does not establish a historical coordinate.
